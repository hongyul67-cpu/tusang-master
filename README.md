# 📐 투상도 마스터

기계·기초 제도 수업용 **투상도(정투상·제3각법) 학습·평가 도구**입니다. 설치·인터넷 없이 브라우저(휴대폰 포함)에서 바로 실행되며, [도면읽기 마스터](https://hongyul67-cpu.github.io/domyeon-master/)와 같은 시리즈입니다.

## 🎮 플레이하기
- **온라인**: https://hongyul67-cpu.github.io/tusang-master/
- **오프라인**: `index.html`을 브라우저로 열기

## 구성
| 항목 | 내용 |
|------|------|
| 📖 배우기 | 투상법 4종·제3각법 배치·3면도 원리를 그림으로 |
| 🧭 모드 1 | 투상법 종류 판별(정투상·등각·사투상·투시) |
| 🧩 모드 2 | 제3각법 3면도 배치·이름(정면도·평면도·우측면도) |
| 🔎 모드 3 | 3D 입체 → 지정 방향의 투상도 고르기 |
| 🏁 종합 점검 | 세 영역 혼합 12문제 |

## 특징
- 선택 후 **제출** 방식(실수 클릭 방지), 파티클·클리어 배너 등 연출(fx.js)
- 교사가 [결과수집 링크](https://hongyul67-cpu.github.io/links/link-builder.html)로 열면 결과를 구글시트로 제출(collector.js) — 시트 탭 `투상도 마스터`
- 활용: 수업 설명자료 · 학습 확인(제출) · 수업 보조도구

## 활용 팁
투상법·단면도 도구와 함께 "도면읽기" 단원 흐름으로 이어서 쓰면 좋아요:
선의 종류 → 투상도 → 단면도 → 치수/기계요소.
